## ✨ Features

* ➕ **Add Tasks** using button or **Enter key**
* ✏️ **Edit Tasks** instantly
* 🗑️ **Delete Tasks** easily
* ☑️ **Mark as Complete** with strikethrough
* 🎉 **Confetti Celebration** when all tasks are done
* 📱 **Fully Responsive UI**
* 🎨 **Modern Gradient Design**

---

## 🚀 How to Use

1️⃣ Open the app in your browser
2️⃣ Type a task and press **Enter** or **+**
3️⃣ Edit ✏️ or delete 🗑️ tasks as needed
4️⃣ Check ✔️ tasks when completed
5️⃣ Finish all tasks to see 🎉 confetti animation
